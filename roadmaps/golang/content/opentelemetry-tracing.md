# OpenTelemetry Tracing

OpenTelemetry supplies APIs and SDKs for traces, metrics and logs. Useful tracing depends on span structure, context propagation and sampling; without them you get unrelated events instead of one request story.

Visit the following resources to learn more:

- [@docs@OpenTelemetry Go documentation](https://opentelemetry.io/docs/languages/go/)
- [@docs@OpenTelemetry Go API](https://pkg.go.dev/go.opentelemetry.io/otel)
