# Prometheus Metrics

Prometheus scrapes numeric time series from an HTTP endpoint. Counters, gauges and histograms cover most service signals. Stable names and bounded labels determine whether the data remains useful after traffic grows.

Visit the following resources to learn more:

- [@docs@Prometheus Go client guide](https://prometheus.io/docs/guides/go-application/)
- [@docs@client_golang documentation](https://pkg.go.dev/github.com/prometheus/client_golang/prometheus)
