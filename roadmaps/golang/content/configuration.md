# Configuration

Configuration is the contract between a service and its deployment environment. Parse flags and environment variables once into a validated struct, fail fast on missing required values, and keep secrets out of binaries and logs.

Visit the following resources to learn more:

- [@article@The Twelve-Factor App: Config](https://12factor.net/config)
- [@docs@os package documentation](https://pkg.go.dev/os#LookupEnv)
