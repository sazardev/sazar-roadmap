# Ent

Ent is a code-generated entity framework. A schema definition produces typed clients, predicates and relationship loaders. It improves safety around data access but adds a generation step and an opinionated model.

Visit the following resources to learn more:

- [@docs@Ent documentation](https://entgo.io/docs/getting-started)
- [@repo@Ent repository](https://github.com/ent/ent)
