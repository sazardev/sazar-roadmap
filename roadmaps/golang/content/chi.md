# Chi

Chi is a small router built on the standard `http.Handler` interface. It composes routes and middleware without taking over configuration, validation or the service layer. Use it when you want explicit HTTP structure and easy testing.

Visit the following resources to learn more:

- [@repo@Chi repository and examples](https://github.com/go-chi/chi)
- [@docs@Chi package documentation](https://pkg.go.dev/github.com/go-chi/chi/v5)
